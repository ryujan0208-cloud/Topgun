## 2. 이번에 바꾸는 것 / 안 바꾸는 것

**바꾼다 (사용자 지시: "거리와 고도는 대회 초기조건으로 모두 변경")**
- 초기 거리 → 라운드 인덱스로 2000/2500/3000ft 순환
- 초기 고도 → 609.6~9144.0m 시드 난수, **양 기체 동일**
- `ownship_randomization` **끈다** — 대회에 없는 산란이고,
  `add_random_init_position`이 `+=`로 **누적**되어 warm 실행에서 위치가 판마다 드리프트한다.

**안 바꾼다 (지시 범위 밖 — 그대로 두고 표시만 한다)**
- **초기 속력**: 공식값은 200~300m/s 랜덤인데 우리는 300 고정으로 유지한다.
  사용자가 "거리와 고도"만 지시했다. **이건 남은 불일치로 명시해 둔다.**
  (오늘 배운 "반쪽 수정" 위험에 해당할 수 있으므로 결과 해석 시 반드시 함께 본다)
- 시나리오 형태(HABFM 헤드온): 이미 일치한다(ownship yaw 0 / target yaw 180).

**BO5의 4·5라운드 거리는 공개 자료에 없다.** 2000/2500/3000 순환으로 가정하고 표시한다.

## 3. 측정 체계 (사용자 지시)

| 구분 | 정의 | 역할 |
|---|---|---|
| **주 기준선** | **cold 15시드** — 시드마다 **새 프로세스**, 대회 초기조건 | 판정의 기본 |
| **필수 게이트** | 동일 초기조건의 **BO3/BO5 persistent** — 한 프로세스에서 3판/5판 연속 | 별도 통과 필요 |
| **legacy** | 기존 5km·7000m warm 결과 | **삭제·무효 처리하지 않는다.** 원거리·고고도 스트레스 자료로 보존 |

시드 k → 거리 `[2000,2500,3000][k % 3] ft`, 고도 `uniform(2000,30000) ft` (시드 k로 재현 가능).
→ 15시드에 세 거리가 각 5회, 서로 다른 고도 15개.

## 4. 이번 재측정 범위 (사용자 지시: "현재 기준 버전과 v40만 우선")

- **v32** (직전 기준 버전) 과 **v40** (현 채택본) **둘만**.
- 상대: 10상대 전체(ACE / onecircle / kwon / v7 / sync / jink / junghwan / SEARCH / STRAIGHT / **jh2**).
- v40은 **되돌리지 않고 "대회조건 재검증 대기" 상태**로 둔다.

## 5. 판정 기준 (결과 보기 전에 고정)

새 조건에서는 v32도 v40도 **기준선이 없다.** 따라서 이번 측정은 **채택/기각 판정이 아니라
새 기준선 수립**이다. 다만 v40의 존치 여부를 가르기 위해 아래를 미리 고정한다.

### A. v40 존치 (대회조건에서)
- **존치**: 승 ≥ v32 승 **그리고** 패 ≤ v32 패 **그리고** 순이득 ≥ v32 순이득
- **재검토**: 위 셋 중 하나라도 미달
- **즉시 되돌림**: **우리 고도이탈(<300m) 패배가 v32보다 3판 이상 많을 때.**
  v40은 하한을 낮춘 변경이고 대회 초기고도가 609m까지 내려가므로 이 위험이 실재한다.
  다른 어떤 지표와도 맞바꾸지 않는다.

### B. BO3/BO5 게이트 (필수)
- 동일 초기조건 persistent 실행에서 **v40의 시리즈 승수가 v32보다 적지 않을 것.**
- 시리즈 판정: 라운드 승 1점, **무승부 0점**(규정집 제6조 3항 4호 다전제),
  BO3는 2승 선취, BO5는 3승 선취.

### C. 함께 반드시 보고
1. 시드별 라인 (집계값만 보지 않는다)
2. 최대 기여 시드 제외값
3. **초기 고도대별 분해** — 저고도(<2000m) / 중(2000~5000m) / 고(>5000m).
   v40은 고도 정책 변경이므로 **고도대별로 갈리는지가 핵심**이다.
4. 우리·상대 최저고도와 고도이탈 건수

## 6. 예측 (결과 보기 전에 적는다)

| 항목 | 예측 | 근거 |
|---|---|---|
| **legacy 대비 전체 성적** | **양쪽 다 크게 달라진다.** 순위가 바뀔 수도 있다 | 5km 진입 국면이 사라진다. v38·v39가 다룬 문제가 통째로 없어진다 |
| v40 vs v32 (대회조건) | **v40 우세가 줄어든다** | v40의 이득은 "상대가 아래로 갈 때 따라간다"인데, 헤드온 근접 시작이면 고도차가 벌어질 시간이 짧다 |
| **저고도 시작(<1500m)** | **v40이 위험하다** | 조준하한 800m·ClimbOut 1000m인데 시작이 609m면 스폰 즉시 하한 아래다. 고도이탈 패배가 나올 수 있다 |
| 고고도 시작(>5000m) | v40 ≈ v32 | 둘 다 하한에 안 닿는다 |
| jh2 | v40 우세 유지하되 폭 감소 | 위와 같은 이유 |

**저고도에서 v40이 위험하다는 예측이 맞으면, v40은 "하한을 낮춘다"가 아니라
"상대 고도에 연동한다"만 남기고 절대하한은 다시 올려야 한다.**

## 7. legacy 보존

기존 5km·7000m warm 결과는 `experiments/legacy_5km_7000m/`로 **이동이 아니라 색인**한다
(파일은 제자리에 두고 어떤 로그가 legacy인지 목록만 만든다).
