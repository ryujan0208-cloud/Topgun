## 1. 초판에서 틀렸던 것

**초판은 1~3라운드를 정면(head-on)으로 가정했다. 근거가 없었다.**

뷰어 화면(사용자 제공)에 프리셋 버튼이 **두 줄**로 있다:
```
[2000ft] [2500ft] [3000ft]        <- 두 기체 간 거리 (운영측 명시적 정정: 고도 아님)
[HABFM] [OBFM_RED] [OBFM_BLUE]    <- 시작 기하
```
**`OBFM_RED`/`OBFM_BLUE`의 존재가 핵심이다.** OBFM = Offensive BFM =
**한쪽이 이미 뒤를 잡은 상태로 시작**한다. 즉 **방어로 시작하는 라운드가 존재할 수 있다.**
우리 스파링은 지금까지 **전부 중립 시작**이었다 — 방어 시작을 한 번도 시험한 적이 없다.

## 3. 아직 **가정**인 것 (반드시 확정해야 함)

| 항목 | 현재 가정 | 왜 불확실한가 |
|---|---|---|
| HABFM의 정확한 각도 | 양측 ATA 0°(정면) | 뷰어 애셋(.uasset)에 있어 못 읽는다. "고애스펙트"는 정면과 빔(3-9)을 모두 포함한다 |
| OBFM의 정확한 각도 | 공세측 ATA 0° / 방어측 180° | 표준 OBFM은 보통 뒤 30° 원뿔이다. 정확한 값 미상 |
| **1~3라운드가 어느 프리셋인가** | **미상** | 운영측이 명시한 적 없다. 랜덤일 수도, 고정일 수도 있다 |

→ **가정을 결과 해석에 명시한다. 확정되면 재측정한다.**

## 4. 축 분리 (합산 금지)

초판은 15시드를 세 거리에 섞어 한 덩어리로 집계했다. **그건 틀렸다.**
아래 축은 **각각 따로 집계하고 먼저 합산하지 않는다.**

| 축 | 값 | 이유 |
|---|---|---|
| 기하 | HABFM / OBFM_BLUE / OBFM_RED | 완전히 다른 경기다. 방어 시작은 처음 시험한다 |
| 거리 | N2000 / N2500 / N3000 | **예선은 단판제라 N2000만** 걸린다. 본선 BO3에서만 셋 다 나온다 |
| 생명주기 | cold / persistent | 실측: 같은 시드에서 0/14 일치, 승수 11 vs 8 |
| 고도대 | 저 <2000m / 중 / 고 >5000m | v40이 고도 정책 변경이라 여기서 갈릴 것으로 예측 |

### ★ 시드 예산 문제 (코덱스 권고안이 놓친 것)
축을 다 나누면 셀이 폭증한다. 우리 규칙은 **셀당 15시드 이상**이다.
```
3기하 × 3거리 × 15시드 × 10상대 × 2버전 = 2,700판 ≈ 21시간
```
현실적이지 않다. **거리당 5시드로 쪼개면 우리 규칙 위반**이므로 그 방법은 안 쓴다.
→ 대신 **단계를 나눈다**(아래 5절).

## 6. 저고도 안전 게이트 (S3, 코덱스 권고 채택)

초기 고도 **2000 / 2500 / 3000 / 5000 ft** × 초기 속도 **200 / 250 / 300 m/s**
× v32/v40 (거리 N2000, 기하 HABFM 고정) = 12셀 × 2버전 × 10시드 = 240판.

**판정 지표(점수와 별개로 독립 판정)**
1. **우리 추락(<300m) 횟수** — v40이 v32보다 3판 이상 많으면 **즉시 되돌림**
2. 최저고도 분포
3. **초기 10초 하강량** — 스폰 직후 바닥으로 파고드는지

## 7. phase별 보고 (코덱스 권고 채택 + 사용자 관찰 반영)

사용자가 뷰어에서 관찰: *"큰 원을 돌다 교차 지점에서 phase가 바뀌며 미세하게 깎여 승부"*.
콘 부피비가 P1:P2:P3 = 1 : 6.36 : 21.37이므로 **후반 phase가 승부를 가를 개연성이 높다.**

모든 결과에 아래를 함께 낸다:
1. **P1/P2/P3별 준 HP·받은 HP**
2. **첫 피해 시각과 그때의 phase**
3. **phase 전환(100s, 150s) 직후 ±2초 피해** ← 사용자 관찰을 직접 겨눔
4. **phase별 WEZ 체류시간**
5. 최대 기여 시드 제외값
6. **무승부를 만든 대칭 선회 궤적 비율** — 양쪽이 같은 방향으로 큰 원을 도는 시간 비율

## 8. 판정 기준 (지금 고정)

새 조건에는 기준선이 없다. **이번 측정은 채택/기각이 아니라 기준선 수립**이다.
다만 v40 존치 여부는 미리 고정한다.

- **존치**: 세 기하 **각각에서** 승 ≥ v32 그리고 패 ≤ v32
- **재검토**: 어느 한 기하에서라도 위 미달
- **즉시 되돌림**: S3에서 **우리 추락이 v32보다 3판 이상 많을 때.** 타협하지 않는다
