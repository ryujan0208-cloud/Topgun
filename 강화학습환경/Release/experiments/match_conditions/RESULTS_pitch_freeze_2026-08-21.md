# ★★ ATA가 9도에서 얼어붙는다 — 원인은 선회율이 아니라 피치 권한이었다 · 2026-08-21

밤새 후보 9종을 기각하는 과정에서, **문제의 성격 자체를 잘못 보고 있었다는 것**이 드러났다.

---

## ① 먼저 — 내가 상황을 잘못 읽었다 (sixdive 무동작)

`sixdive`(뒤잡힘 시 하강 반전)는 **90판 중 yuno전 15/15판이 완전 무동작**이었다.

원인: 게이트 `eAta<15 && dist<1500 && ataDeg>60` 중 마지막 조건이 **한 번도 성립하지 않는다.**

**실측 — 상대가 우리를 겨눌 때 우리 ATA 분포 (1474틱):**
```
중앙 9.3도   75% 15.9   90% 20.9   최대 27.9
ATA > 30도 인 비율:  0.0%
```

**상대가 우리를 겨눌 때 우리도 상대를 겨누고 있다.**
`enemyAtaDeg < 15`는 "상대 기수가 우리를 향한다"는 뜻이지 **"우리 뒤에 있다"는 뜻이 아니다.**
내가 그 둘을 동일시했다. 이건 뒤잡힘이 아니라 **서로 기수를 맞댄 정면 대치**다.

⚠ 8/18 스크림의 "등 보이고 21초 도주"(우리 ATA 120~161도)는 **yuno 기체**였다.
   우리 기체는 yuno전에서 그런 상황에 빠지지 않는다.

## ② 진짜 문제 — ATA가 9~12도에서 **정지**한다

**사거리 안 + ATA<20도 구간 46개 (10틱 이상):**

| # | 지속 | ATA 시작 | ATA 최소 | ATA 끝 | 양상 |
|---|---|---|---|---|---|
| 1 | **15.47초** | 8.1° | **8.13°** | 20.0° | 정체 |
| 4 | 6.80초 | 10.8° | 9.26° | 20.0° | 정체 |
| 7 | 5.10초 | 9.0° | **9.02°** | 20.0° | **부호전환 0회** |

```
구간별 최소 ATA 중앙 10.77도
1도 이내로 들어간 구간: 46개 중 1개
```

**7번은 5초 동안 9.00 -> 9.02도.** 1번은 **15.5초를 8도에서** 못 움직였다.

★ **선회율 부족이면 ATA가 요동쳐야 한다. 그런데 정지해 있다.**
   **정지된 오차는 제어 평형의 신호다.**

## ③ 원인 — Roll_Effect가 피치를 죽인다

```cpp
Roll_Effect = 1 - clamp(|UTAngle| / 90, 0, 1);
PitchCMD    = ERROR_Effect * Roll_Effect * Horizon_Effect * (-1);
```

**ATA 5~15도 구간 4219틱 실측:**

| | Roll_Effect 중앙 | 실효 PitchCMD 중앙 | 피치 억제(<0.3) |
|---|---|---|---|
| **ATA 5~15도** | **0.150** | **0.194** | **53.5%** |
| 그 외 | 0.000 | 0.000 | 62.3% |

**UTAngle 중앙 76.5도.** 90도에 가까우면 `Roll_Effect -> 0`이라
`ERROR_Effect`가 포화(1.5)여도 **실효 피치가 최대의 19%로 떨어진다.**

**제어기 논리 자체는 옳은 BFM이다** — "먼저 롤해서 표적을 당길 평면에 넣고, 그다음 당긴다".
문제는 **롤이 끝나기 전에 표적이 또 옆으로 돌아가 영원히 '롤 중'인 채 피치가 눌리는 것**이다.

### ⚠ 내가 이 가능성을 한 번 접었다가 되찾았다

앞서 "7.65도면 ERROR_Effect가 포화라 권한은 충분하다"며 기각했는데,
`PitchCMD = ERROR_Effect x **Roll_Effect** x Horizon_Effect` 이므로
**Roll_Effect가 0이면 포화여도 피치가 0**이다. 곱셈항을 하나만 보고 판단한 실수였다.

## ④ 지렛대 — VP가 UTAngle을 정한다

`Controller_CY`는 제출 제약이라 못 건드린다. **그러나 UTAngle은 VP 위치가 결정한다.**
VP를 **우리 자신의 Up 방향**으로 올리면 수직성분에 Up 성분이 생겨
UTAngle이 줄고 -> Roll_Effect가 오르고 -> **피치 권한이 돌아온다.**

→ `unlockpitch` 구현 (절제 플래그, 기본 꺼짐):
```cpp
if (dist < 914 && 4 < ataDeg < 16) {
    // 기수축 수직성분과 내 Up 사이 각(UTAngle)으로 Roll_Effect를 재현
    if (rollEff < 0.40)
        predicted = predicted + myUp * (perpLen * 0.8);
}
```

**★ 앞서 기각된 조준 게이트 5종과 다른 축이다.**
그것들은 **리드(상대 속도 방향)** 를 건드려 추종 기하를 무너뜨렸다(v25와 같은 실패).
이건 **우리 양력면 안에서의 오프셋**이라 추종 기하를 건드리지 않는다.

판정 기준(사전 고정): 3상대 준데미지 퇴행 없음 AND yuno 순이득 개선 AND 분산 통과.
