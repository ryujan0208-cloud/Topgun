## 판정 기준 (전부 결과 보기 전 고정)

- 채택: **3상대 모두 준데미지 퇴행 없음** AND yuno 순이득 개선
- 즉시 기각: 어느 상대든 준데미지 감소 (v25 실패 양식)
- `divebait` 추가: **우리 추락 1건이라도 = 즉시 기각** (규정상 고도 300m 미만 즉시 패배)
- 분산 검사: 최대 1~3판 제외 후에도 부호·크기 유지
- 메커니즘 설명 못 하면 채택 안 함 (판정원칙 1)

## 실행 규칙 (2026-08-19 갱신)

- **코덱스 작업 중 → 배치 순차 실행.** 지금 도는 3개가 마지막 병렬.
- 배치는 상대별로 쪼갠다(오늘 4회 중단됨. 이어받기가 쉬워야 한다).
- 제출본(`AIP_final.dll`)은 검증 통과 전까지 건드리지 않는다.

## 오늘 확정된 것 (되돌리지 않는다)

- **v44** 좌표 이중변환 2곳 수정 — 실서버 실전 검증 완료
- **v45** 강하 클램프 해제 — 45판 사전기준 통과 + 제출본 등가 45/45
- 기각: 조준게이트 5종 / `mergeslow` / `standoff` / `dwell`
