## 이 자료들이 여전히 유효한 용도

**원거리 진입·고고도 스트레스 시험.** 대회에는 없는 국면이지만,
"5km에서 시작해 상대를 잡아야 하는" 상황에서의 거동을 보여준다.
특히 아래 발견들은 legacy 조건에서 나왔고 그 조건에서는 여전히 참이다:

- 원거리 풀스로틀 → 496 m/s → 선회반경 28km (v38·v39의 근거)
- v32 상승 클램프 해제의 효과 (사격 2틱 → 16틱)
- 절제 실험 7종의 기능별 중요도 순위
- dt 버그의 정량화(omega 7~9배)
- v40 채택 근거(1800m 벽에 매 판 걸림)

## ⚠ 대회조건 결과와 **합산하지 않는다**

같은 상대·같은 시드라도 다른 경기다. 표에 나란히 놓을 때는 반드시 조건을 병기한다.
