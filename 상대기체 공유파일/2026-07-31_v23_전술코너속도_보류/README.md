# v23 / v23b — 전술적 코너속도 (조준 개선 확인, 채택 보류)

## 가설
실측: 속도별 지속 선회율 **240~270m/s에서 27°/s vs 420~450m/s에서 7°/s (4배 차이)**.
그런데 우리 교전속도 중앙값이 **422m/s = 코너속도의 1.7배** → 선회율이 최대치의 1/4.
→ "기수를 돌려야 하는 순간에만" 코너속도로 감속하면 조준이 가능해질 것.

**과거 실패(v4/v9~v12 "감속 금지")와의 차이**: 그들은 *항상* 감속해 직선 추격에서 뒤처졌다.
v23은 3조건 동시 충족 시에만 감속: (a)교전거리<2500m (b)ATA>12° (c)과속(>290m/s).
정렬되면 즉시 풀스로틀 복귀. 재가속 rate를 감속보다 빠르게(0.030 vs 0.008).
- **v23b 추가**: 적이 나를 겨누면(적ATA<35°) 감속 금지 = 방어 시 에너지 보존.

### ✗ 채택 못 한 이유 — S3(방어) kwon 피격 45.5 → **385** 폭발

(최소ATA 141.9°) → 적 사거리 안에 계속 체류. v20b(45.5)보다 8배 악화.
