# v29 — 에피소드 리셋 버그 수정

## 버그
v18에서 넣은 `if (RunningTime < lastRunTime) {상태 리셋}`이 **한 번도 발동한 적 없음**.
RunningTime은 BlackBoard 생성자에서만 0이고 매 틱 증가만 하는데, BTActionProvider.reset()이
BT를 재생성하지 않아("Keep native BT alive across episode resets") 되감기는 일이 없다.
→ 새 판이 직전 판의 기수이력(fwdHist)·스로틀(lastThr/lastEvThr)을 물려받고 있었다.
→ Task_Jink의 "결정론적 재현" 주장도 성립하지 않았다.

## 수정
**위치 점프 감지**로 교체. 리셋 시 기체가 km 단위로 순간이동한다
(1틱에 2km = 120km/s는 정상 비행으로 불가능).
적용: Task_LeadPredict(fwdHist/스로틀), Task_Evade(스로틀), Task_Jink(저킹 시퀀스).

## 검증 1 — 재현성
같은 시드를 **단독 실행 vs 배치 3번째** → 결과 완전 일치.
(이전엔 배치 순서에 따라 달랐다: 단독 seed0 +1053승 vs 배치 seed0 -119무)

이유: 이전엔 새 판이 직전 판의 스로틀·기수이력을 물려받아 초반 몇 초가 오염됐는데,
이제 매 판 깨끗하게 시작한다. **버그 수정이 정확성뿐 아니라 실제 성능을 올렸다.**
