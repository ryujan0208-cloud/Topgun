## 유일한 실패 — seed11 고도 추락 (G1 위반)

## 채택 보류 사유 — 규칙 의존
seed11의 승패가 **미확인 대회 규칙에 달림**:
- "고도하한 = 즉시 패배" 규칙 → v21은 1패, v20b(0패)보다 나쁨 → 보류/안전망 필요
- "종료 시 HP 비교" 규칙 → seed11은 0.97 vs 0.55 = **승리**, v21이 전 지표 우위 → 즉시 채택

→ 사용자에게 이미 물어둔 "타임아웃/종료 판정 규칙"이 이 결정을 가른다.
   그 전까지 현역은 안전한 v20b 유지. v21은 후보 보존.
   근본 해결책 = 절대고도 안전망(v22 백로그) — v21 위에 얹으면 규칙 무관하게 최선.
