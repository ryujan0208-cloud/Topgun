# v31 — 고도 게이트 하강 나선 (판정 보류: 상대 유형에 따라 갈림)

## 배경 — "물리 한계"가 아니었다
사용자 지적으로 선회 성능을 재측정(turn_perf2.py)한 결과, 이전의 "물리 한계" 주장이 반증됐다.
내 측정 결함 3가지: ①yaw로만 측정 ②수평선회만 시험 ③지속값만 측정.
| 기동 | 지속 | 순간 | 반경 |
|---|---|---|---|
| 수평선회(뱅크82) | 11.3°/s | 17.9°/s | 610~1007m |
| **하강나선(뱅크110)** | **25.4** | **42.8** | **493~518m** |
156° 되돌리기 13초 -> **3.6초**, 최소반경 1007m -> **297~518m(사거리 914m 안쪽)**

## 대가 — 고도 (실측)
| 스로틀 | 고도손실 | 156° 비용 | 최소 진입고도 |
|---|---|---|---|
| 0.30 | 325 m/s | **1967m** | 2267m |
| 0.85 | 383 m/s | 2529m | 2829m |
고도손실/속도 ≈ 1.0 = 거의 수직 강하. 측정 중 `altitude below min`으로 죽은 케이스 발생.
-> **고도 게이트 필수.**

## 구현 (Task_Evade)
```
고도 > 3000m : downMix 0.55 -> 1.80 (고도에 비례해 깊게)  = 하강 나선
2200~3000m   : 0 -> 0.55 (연속 접속)                      = 완만한 out-of-plane
< 2200m      : -0.25                                      = 상승(지면 회피)
```

## 해석 (메커니즘)
**수평면에 갇힌 상대(onecircle, kwon)에겐 강력** — 선회 우위가 반경 싸움에서 그대로 나타남.
**3D를 쓰는 상대(ACE)에겐 덜 유효** — ACE는 양력벡터 제어로 수직을 따라올 수 있는 유일한 상대.
우리가 아래로 빠지면 따라 내려오며 위치 우위를 유지하고, 우리는 방어에 시간을 쓴다
(피격이 0.157->0.126으로 준 것도 같은 이유).

## 판정 보류 사유
총량은 v31 우세(dealt +30%, taken 동일)이나 **ACE 준데미지 54% 감소**가 걸린다.
ACE가 "미지의 고도화된 상대" 대리라는 점에서 중요하다.
**승/무/패 카운트(시드별)가 있어야 최종 판정 가능** — 우리 판정 기준은 승리 수가 1순위.
