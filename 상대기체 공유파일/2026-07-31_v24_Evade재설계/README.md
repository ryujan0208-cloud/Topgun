# v24 — Evade 재설계 (시나리오 판정 최고 기록)

## 문제
기존 Evade = **상대 쪽 순수 수평 브레이크턴 + 스로틀 방치**(직전 값 유지) 하나뿐.
- Syllabus S3(적이 우리 800m 뒤): 물림 35~39%, 피격 45.5틱, **최소ATA 176.9°**(한 번도 못 돌림)
- v7 로그: Evade 발동 45초 내내 거리 777→150m로 **오히려 좁혀지며** 82틱 피격
→ 트리거는 정상, **기동 자체가 무력**.

## 해법 — BFM 정석 3요소 (전부 물리 원리라 상대 불문)
`Task_Evade.cpp` 수정:
1. **out-of-plane**: 수평이 아니라 기수를 낮춘 사선 브레이크(`downMix` 0.55).
   추적자의 조준면을 3D로 강제해 리드 해를 깨고, 중력이 선회를 도와 같은 G에서 선회율↑
2. **코너속도**: 방어의 목표는 도주가 아니라 "더 빨리 도는 것".
   과속이면 감속(최저 0.30), 변화율 0.040으로 즉응. **Evade가 스로틀을 명시적으로 잡는다.**
3. **고도 안전**: 3500m 아래부터 하강 성분 축소, 2200m 아래는 상승 전환, VP Z하한 1500m.
   (규정 제6조: 고도<300m = 즉시 패배)

## 남은 문제 — S3 kwon 피격 768틱 (정직한 기록)
v20b 45.5 → v23b 385 → **v24 768.5**로 오히려 악화. 생존은 함(원거리 피격이라 데미지 계수 작음).
**원인: 에너지 트레이드오프.** 뒤를 물린 채 감속하면 선회율은 얻지만 상대가 더 오래 뒤에 머문다.
v7(단순 추격자)에겐 out-of-plane이 통하는데(피격 1.0), kwon(정밀 추적)에겐 감속이 표적을 만든다.
→ **방어가 상대 유형에 따라 갈린다 = 아직 강건하지 않다.**

**다음 후보**: 방어 국면을 2단으로 — ①초기: 코너속도 브레이크(선회율 확보)
②상대가 못 따라오면 유지, ③계속 물리면 **언로드 가속 이탈(extend)** 로 전환해 거리를 벌린다.
지금은 계속 돌기만 해서 상대 사거리에 머문다.
