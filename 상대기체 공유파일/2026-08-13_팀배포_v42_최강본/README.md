## 우리 쪽에서 나온 것 중 그쪽에도 해당될 것

### 1. 🔴 `DECO_AltitudeCheck`는 예측식이라 실효 하한이 명목값의 1.6배다

템플릿 원본(v22c 이후 우리가 넣은 것일 수 있으니 그쪽 코드 확인 필요):

```cpp
predAlt = CurrentAlt + MySpeed_MS * sin(pitch) * 5.0;   // 5초 뒤 예상 고도
if (CurrentAlt < MinAlt || predAlt < MinAlt) -> ClimbOut
```

**실효 하한 = MinAlt + 5초치 하강량.** 250m/s로 60° 강하하면 `predAlt = 고도 − 1080m`이라
**MinAlt=1000일 때 2080m에서 이미 발동**합니다.

우리 실측(30판): 명목 1000인데 **발동 고도 중앙 1657m, 최고 3063m, 30판 중 27판**에서 걸렸고
ClimbOut이 BT 틱의 10.4%를 점유했습니다. **급선회는 곧 하강이라 공격적으로 돌 때마다
추격이 끊깁니다.**

MinAlt를 1000 → 700으로 내린 것만으로 방어 시작 매치업이 **8승 1무 21패 → 21승 0무 9패**,
순이득 −6.56 → +11.12가 됐습니다. 우리 추락은 0건이고 최저고도 중앙 914m / 최소 658m입니다.

⚠ **예측 항 자체는 없애면 안 됩니다.** 실제 추락 사고(1800m에서 걸린 뒤 1461m를 더 잃음)
때문에 넣은 것입니다. 값만 내리세요.
⚠ **조준점 하한과 이 MinAlt는 반드시 같이 낮춰야 합니다.** 하나만 낮추면
"800m를 겨누고 1600m에서 기수를 채올리는" 상태가 됩니다.

### 2. 🔴 근거리 6시 위협에서 **이탈은 선회진입보다 나쁘다**

우리는 `Task_Evade`(횡 브레이크 이탈) 분기를 **제거**해서 이득을 봤습니다.

같은 t=0 기하(거리 612m, 우리 ATA 180°, 상대 ATA 30°)에서:
- 게이트가 안 열린 판 → 우리가 안으로 돌아 **HP 1.000으로 승**
- 게이트가 100% 열린 판 → 등을 돌리고 **37초에 격추**

제거 결과: 대회조건 90판 71/2/17 → 77/5/8, legacy 150판 102/42/6 → 110/37/3, 퇴행 셀 0.
Syllabus 방어BFM이 `WEAK(생존만)` → `PASS(반전 성공)`으로 올랐습니다.

⚠ **게이트를 좁히는 건 답이 아닙니다.** 1100→400으로 좁혀봤더니 4승 0무 11패로
기준선과 같았습니다. 우리는 최근접 중앙 216m까지 파고들어 **좁힌 게이트도 결국 열리고,
더 늦게·더 가까운 거리에서 열리므로 오히려 나쁩니다.**

### 3. 🟠 우리는 사격 구역을 **통과**합니다 (그쪽 3-1과 같은 증상일 수 있음)

조준 성립 순간의 실측(중립 기하):

| | 거리 중앙 | 그때 거리변화율 |
|---|---|---|
| 우리 | **828 m** | **−19 m/s** (90%가 접근 중) |
| 상대 | **393 m** | −6 m/s |

대미지가 `(914.4−거리)/762`로 거리 반비례라 **같은 조준 1틱의 값어치가 4.5배 차이**납니다.
우리는 최근접 중앙 216m까지 밀고 들어가고 30판 중 12판은 **사격 최소거리 152.4m 안쪽**까지
들어갑니다(= 쏠 수 없는 자리).

**거리대별로 보면 원인이 보입니다:**

| 거리 | 우리 ATA | 상대 ATA |
|---|---|---|
| 600~914m | 19~28° | 139~141° |
| 152~600m | **95~107°** | 62~69° |

**가까워질수록 각도를 잃습니다.** 속도매칭·스로틀은 정상 작동하므로(근거리 thr 0.84,
dV ±2) 속도가 아니라 기하 문제입니다.

그쪽 3-1(“I항 상시 포화 → 반스틱 상시 당김 → 505m/s 낼 기체가 421m/s”)과
같은 뿌리일 수 있습니다. 우리는 아직 제어기를 안 건드렸습니다.

### 4. ⚠ 우리가 기각한 것 (중복 삽질 방지)
