# v32 — 상승 VP 클램프 해제 (**채택**). 조준 병목의 실체였다.

## 한 줄
`climbSlope = dist * 0.5` 는 거리와 무관하게 **위로 최대 26.57도**(atan 0.5)를 뜻했다.
상대는 사거리 안 시간의 절반에서 그보다 가파르게 위에 있었다(**필요 앙각 중앙값 59.1도**).
즉 **VP가 상대를 가리키지 못하도록 구조적으로 잘리고 있었다.**

## 왜 이 값이었나 (원인)
`climbSlope`는 `diveSlope`를 **대칭으로 복사한 값**이다. 그런데
- **강하** 클램프에는 지면 충돌(min_altitude 300m = 즉시 패배)이라는 물리적 근거가 있다.
- **상승**에는 그런 위험이 없다. 대칭이어야 할 이유가 처음부터 없었다.
보강 근거: v19 블록 주석에 이미 반증이 있었다 — **"이 시뮬은 상승이 속도를 안 깎는다."**

## 변경
```
climbSlope: dist*0.5 -> dist*3.0   (앙각 26.6 -> 71.6도)
diveSlope : dist*0.5 그대로         (지면 충돌 위험은 실재. 아래로잘림은 13.5%로 병목 아님)
```
