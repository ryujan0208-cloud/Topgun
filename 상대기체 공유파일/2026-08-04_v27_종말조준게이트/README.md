# v27 — 종말 조준 게이트 (현역 채택)

## 변경 (v26 대비 한 블록)
`Task_LeadPredict.cpp`: 사거리 안에서 **ATA가 작을 때만** 리드를 끈다.
```cpp
if (dist < 914.0 && ataDeg < 10.0) {
    double fade = (ataDeg - 3.0) / 7.0;   // ATA 10도:리드유지 -> 3도이하:순수조준
    leadTime *= clamp(fade, 0, 1);
}
```

## v25(기각)와의 결정적 차이
v25는 **거리**로 리드를 껐다가 추격 국면까지 순수조준이 되어 추종 기하가 붕괴했다
(dealt 4.34 -> 1.53). v27은 **ATA로 게이트**한다 — 추격 중(ATA 큼)엔 리드 100% 유지,
정렬된 뒤(ATA<10)에만 끈다. 추종은 보존하고 마지막 조준만 다듬는다.

## 정정 — onecircle 진단이 틀렸다
이전에 "최소 ATA 1.21도로 0.21도 부족"이라 했으나, 그건 **운 좋은 한순간**이었다.
실제로는 **ATA가 10도 아래로 내려가는 일 자체가 0.2%** — 정렬 자체를 못 한다.
문제의 성격은 "정밀도"가 아니라 **"각도를 아예 못 얻음"**.
원인: 선회율이 대등(11.7 vs 11.9도/s)해 수평 선회전에서는 어느 쪽도 각을 못 얻는다.
= 동급기끼리의 원써클은 구조적 교착. 깨려면 **수직 기동**(out-of-plane)이 필요하다.
