# ★★ v46 채택 — 스로틀 변화율 제한 해제 · 2026-08-21

v45(좌표 2곳 + 강하 클램프) 위에 **한 줄**을 얹었다. 트리(XML)는 v42 이후 그대로다.

## 무엇을 바꿨나

```cpp
// 이전 (v18~v45)
float stepUse = 0.008f;   // 스로틀 변화율. 10Hz에서 0.08/s => 0↔1에 12.5초

// v46 (기본값)
if (!Ablation::off("v46thr")) stepUse = 1.0f;   // 한 틱에 전 구간 이동
```

되돌리려면 절제 플래그 `v46thr` 하나.

## ★ 규명된 메커니즘 (vs yuno, 같은 4시드, 사거리 안 득점 기회)

| | **우리 ≤1°** | 우리 ≤3° | **상대 ≤1°** | 상대 ≤3° |
|---|---|---|---|---|
| v45 | **4틱** | 110 | **99틱** | 156 |
| **v46** | **30틱** | 122 | **46틱** | 75 |

**우리 득점 기회 7.5배, 상대 득점 기회 절반.**
준데미지 0.215→0.447(2배), 받은 0.664→0.130(1/5)이 이 수치에서 나온다.

**왜 그런가 — 두 갈래다:**

**① 우리 쪽 — 평균은 나빠지고 극단이 좋아진다**

| | v45 | v46 |
|---|---|---|
| 사거리 안 ATA 중앙 | 48.4° | **68.5°** (나빠짐) |
| 최소 ATA | 0.19° | **0.09°** (좋아짐) |

**사격 판정은 평균이 아니라 "한 틱이라도 1° 안"** 이므로 극단이 보상받는다.

**② 상대 쪽 — 리드 예측이 빗나간다**
우리 속도가 예측 불가능해지면서 상대 ATA 중앙이 112.9° → 95.1°로 바뀌고
**상대의 ≤1° 틱이 99 → 46으로 반토막**난다.

즉 **"우리가 더 잘 쏘게" 되는 동시에 "상대가 우리를 못 쏘게"** 만든다.

## 성적 (30시드 x 3상대, 대회조건 10Hz)

| 표본 | v45 | **v46** |
|---|---|---|
| 1차 (k×3+1) | 27승 13무 **5패** | **30승 12무 3패** |
| 2차 (k×3+2) | 23승 19무 **3패** | 22승 22무 **1패** |
| **합산** | **50승 32무 8패** | **52승 34무 4패** |

**승 +2, 패 −4. 두 독립 표본 모두 패가 줄었다.**
yuno전 순이득이 둘 다 음 → 양으로 바뀐다 (−0.449→+0.317, −0.519→+0.102).
**우리 추락 0 / 180.**

## ⚠ 판정 기준을 고쳤다 — 이게 이번 채택의 핵심이다

처음엔 **"어느 상대든 준데미지가 줄면 즉시 기각"** 으로 보고 **이미 기각했었다.**

그 기준은 v25의 실패 양식(준데미지 4.34→1.53과 함께 **승수도 6승→4승 붕괴**)을 막으려던 것이다.
**v46은 정반대다 — 준데미지는 줄지만 승수가 는다.**

규정이 **200초 타임아웃 후 HP 비교**이므로:
- jung·jh2는 **받은 데미지가 0**이다. 준데미지가 13.671이든 13.041이든 **어차피 다 이긴다.**
- yuno는 1승5패 → 3승3패로 **판이 바뀐다.**

CLAUDE.md 가치 순서는 **승리 > 준 데미지 > 무피격**이다. 준데미지를 1순위처럼 쓴 것이 실수였다.
