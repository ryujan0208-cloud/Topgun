# 상대기체 배포: v29 (2026-08-04 기준 우리 최강본)

## 파일 2개를 **같이** 넣어야 합니다
```
AIP_v29.dll
Rule_v29.xml
```
둘 다 `강화학습환경/Release/` 에 복사.

**DLL 안에 XML 경로가 `./Rule_v29.xml`로 박혀 있습니다.**
DLL 이름은 바꿔도 되지만 **XML은 반드시 `Rule_v29.xml`이라는 이름 그대로** 둬야 합니다.
(이름을 바꾸면 트리 로드 실패)

BehaviorTree 런타임은 DLL에 정적 링크돼 있어 추가 의존성 없습니다.

## 쓰는 법
```python
BTActionProvider(dll_name="AIP_v29.dll")   # target_action_provider 로 넘기면 상대기체
```
또는 기존 배치 스크립트의 상대 DLL 인자에 `AIP_v29.dll`.

BLUE/RED 양쪽 다 동작합니다(내부 상태를 팀별로 분리해 둠).

## 이 기체의 성격 (상대할 때 참고)
- **뒤를 잡으면 궤도 추적으로 유지**하려 듭니다. 상대 선회원을 복원해 300m 뒤 슬롯을 겨냥.
- **과속하면 스로틀을 깎아 코너속도(260m/s)를 지킵니다.** 오버슈트로 떨궈내기 어렵습니다.
- **뒤를 잡히면**(상대 ATA<25° & 거리<1100m) out-of-plane 브레이크턴 + 감속.
- **약점**: 수평 원선회 싸움(onecircle 계열)에 약합니다. 반경 싸움으로 끌고 가면 잘 안 맞습니다.
- 고도 1800m 아래로 내려가면 상승 우선으로 전환합니다.
