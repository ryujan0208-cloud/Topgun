# 상대기체 배포: v32 — 2026-08-06 기준 우리 채택본

## 파일 2개를 **같이** 넣어야 합니다
```
AIP_v32.dll
Rule_v32.xml
```
둘 다 `강화학습환경/Release/` 에 복사.

**DLL 안에 XML 경로가 `./Rule_v32.xml`로 박혀 있습니다.**
DLL 이름은 바꿔도 되지만 **XML은 `Rule_v32.xml`이라는 이름 그대로** 둬야 합니다.
BehaviorTree 런타임은 DLL에 정적 링크돼 있어 추가 의존성 없습니다.

## 쓰는 법
```python
BTActionProvider(dll_name="AIP_v32.dll")   # target_action_provider 로 넘기면 상대기체
```
BLUE/RED 양쪽 다 동작합니다(내부 상태를 팀별로 분리해 둠).

## 이 기체의 성격 (상대할 때 참고)
- **수직으로 쫓아옵니다.** v32의 핵심이 상승 조준 한계를 26.6° → 71.6°로 푼 것입니다.
  위로 도망쳐도 기수가 따라옵니다. v29 이전 버전은 위를 못 봤습니다.
- **뒤를 잡으면 궤도 추적으로 유지**합니다(상대 선회원을 복원해 300m 뒤 슬롯을 겨냥).
- **과속하면 스로틀을 깎습니다**(코너속도 260m/s). 단순 오버슈트로는 잘 안 떨어집니다.
- **뒤를 잡히면**(상대 ATA<25° & 거리<1100m) out-of-plane 브레이크턴 + 감속.
- 고도 1800m 아래로 내려가면 상승 우선으로 전환합니다.

## 약점 (이게 더 쓸모 있을 겁니다)
1. **수평 원선회 싸움에 약합니다.** onecircle 상대 15판 중 12판이 0대0 무승부.
   선회율이 대등하면(11.7 vs 11.9°/s) 각도차를 못 좁힙니다. **반경 싸움으로 끌고 가세요.**
2. **거리 1100~2000m에서 뒤를 잡히면 대응 분기가 없습니다.**
   Evade 조건이 `거리<1100m`이라 그 밖에서 6시에 붙으면 교착으로 갑니다.
3. **`ClimbOut`(고도<1800m)이 예측 가능합니다.** 조건이 고도 하나뿐이고 침하율을 안 봅니다.
   저고도로 끌고 가면 상승만 하느라 공격을 못 합니다.
