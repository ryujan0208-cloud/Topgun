## 무엇을 바꿨나

```cpp
// Task_LeadPredict.cpp — 조준점 절대 하한
AIM_FLOOR = clamp(TargetLocation.Z - 300.0, 800.0, 1500.0);   // v32: 상수 1500
```
```xml
<!-- Rule_v40.xml -->
<DECO_AltitudeCheck name="AltCheck" MinAlt="1000" .../>        <!-- v32: 1800 -->
```

**둘을 반드시 같이 낮춘다.** 하나만 낮추면 내려가려다 벽에 부딪혀 에너지만 잃는다.

## 왜 (실측)

v32는 **매 판 1800m 벽에 걸려 있었다.** jh2전 15판 실측:

```
우리 최저고도   중앙 1797m   최소 1780m     ← DECO_AltitudeCheck(1800m)에 정확히 걸림
상대 최저고도   중앙 1013m   최소  403m     ← 즉사 고도(300m) 103m 위까지 사용
```

`DECO_AltitudeCheck`는 `ReactiveFallback`의 **첫 분기**다. 상대가 1800m 아래로 내려가면
우리 트리는 통째로 `ClimbOut`으로 넘어가 **추격이 중단된다.**
→ "우리가 능력의 55%만 선회한다"(6.1°/s vs 능력 11°/s)의 정체는 **선회가 아니라 상승**이었다.

**우리는 기동 공간 1000m를 스스로 포기하고 있었다.**

### 발견 경로
팀원의 8/6판과 최신판(`cf49f0e`) XML을 비교했더니 **노드 59개 중 두 숫자만** 달랐다:
```
PreventLandCrash   FloorHard 1800 → 800 ,  FloorSoft 3200 → 1500
```
그 한 변경으로 그쪽 전적이 0승15패 → 11승4패로 뒤집혔다. 우리 실측이 같은 곳을 가리켰다.

## 기각한 중간안 — 무조건 낮추면 안 된다

| 안 | jh2 | kwon | 판정 |
|---|---|---|---|
| `divefree` (강하 클램프만 완화) | 4승→**1승** | | 기각. 조준만 내리고 **벽은 그대로** = 최악의 조합 |
| `lowfloor` (무조건 800m) | 4승→11승 | 11승→**8승** | 기각. 승수 −3 조항 |
| **`lowfloor2` = v40** (상대 고도 연동) | 4승→**12승** | 11승→9승 | **채택** |

`lowfloor`의 kwon 퇴행을 실측으로 규명한 것이 최종안으로 이어졌다:
```
             우리 최저   우리 중앙   상대 최저   준 데미지
v32           1865m      5963m      1538m      10.99
lowfloor      1160m      5006m      1490m       7.02
```
**kwon은 1500m 아래로 안 내려간다.** 그런데 우리만 1000m 더 내려가 상대 없는 고도에 있었다.
→ **고도를 내주는 것은 상대를 따라갈 때만 이득이다.**
   상대 이름이 아니라 **상대의 현재 고도**로만 표현되므로 특정 상대 튜닝이 아니다.

## 검증

- **대조군**: 게이트 미설정 시 v32와 시드별 완전 일치(v7 15시드)
- **승격 검증**: 환경변수 없는 `AIP_v40.dll` == 게이트판 `lowfloor2`, **시드별 30판 완전 일치**
- **우리 고도이탈 패배 0건** (사전등록 기각선 3건). 오히려 **상대를 4번 지면으로 몰았다**
- **최대 기여 시드**: jh2 11% / kwon 14% / ACE 14% / v7 16% — 분산이 아니다
  (onecircle 131%·sync 100%는 늘 그렇듯 분산이라 판정에 쓰지 않았다)
- 사전등록: 커밋 `9e5c178` (**결과 보기 전** 고정)

## 남은 퇴행 (숨기지 않는다)

kwon −2, v7 −2, SEARCH −2, sync −2. **전부 패가 늘지 않고 무승부만 늘었다** —
못 끝내는 것이지 지는 것이 아니다. 공통 원인은 `MinAlt=1000`이 **무조건**이라
상대가 높아도 교전 고도가 아래로 가라앉는 것으로 보인다.
조준점 하한은 상대 연동으로 고쳤지만 **ClimbOut 임계는 아직 상수**다.
→ 다음 후보: `DECO_AltitudeCheck`도 상대 고도에 연동. 별도 사전등록 필요.
