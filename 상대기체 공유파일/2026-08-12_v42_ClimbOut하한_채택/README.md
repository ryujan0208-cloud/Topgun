# v42 채택 — ClimbOut 하한 1000 → 700 · 2026-08-12

**변경은 XML 한 값뿐이다. DLL 재빌드 없음.** (v41도 XML 한 곳이었다 — 두 판 연속 무빌드)

```xml
<DECO_AltitudeCheck name="AltCheck" MinAlt="700" BB="{BB}"/>   <!-- v41: 1000 -->
```

## ★ 발견 — 이 게이트는 **예측식**이다

`BT_Content/Decorator/DECO_AltitudeCheck.cpp` (v22c에서 예측 항 추가, `source/`에 사본):

```cpp
double zdot    = MySpeed_MS * sin(pitchRad);      // 하강률(음수)
double predAlt = CurrentAlt + zdot * 5.0;          // 5초 뒤 예상 고도
if (CurrentAlt < MinAlt || predAlt < MinAlt) -> ClimbOut
```

**실효 하한 = MinAlt + 5초치 하강량.** 250 m/s로 60° 강하하면 **2082m에서 이미 발동**한다.

v41 실측(OBFM_RED 라운드2·3 30판):

| 명목 MinAlt | 실제 발동 고도(중앙) | 최고 | 발동한 판 | ClimbOut 틱 점유 |
|---|---|---|---|---|
| 1000 m | **1657 m** | **3063 m** | **27 / 30** | **10.4%** |

**급선회는 곧 하강이므로 공격적으로 돌 때마다 추격이 끊겼다.**
지는 판이 이기는 판보다 ClimbOut 체류가 54% 많았다(7.4% vs 4.8%).

### 이것이 만든 "반쪽 수정"

v40이 조준 하한(`AIM_FLOOR`)을 상대 고도 연동으로 **800m**까지 내렸는데
ClimbOut 실효 하한은 **약 1600m**로 남았다.
`CLAUDE.md`가 스스로 경고한 상태를 그대로 두고 있었다:
> ⚠ 조준하한과 MinAlt는 반드시 같이 낮춘다. 하나만 낮추면 벽에 부딪혀 에너지만 잃는다.

**800m를 겨누고 1600m에서 기수를 채올리고 있었다.**

### ⚠ 메커니즘이 절반만 설명된다 — 그대로 적는다

고도대별 우리 ATA 중앙값 / 사격 성립률:

| 고도대 | v41 | v42 |
|---|---|---|
| 1200~1700m | 128.2° / 0.18% | **69.8° / 5.37%** |
| 1700~2400m | 122.4° / 0.50% | **62.7° / 5.12%** |
| 2400~4000m | 119.3° / 0.59% | **74.7° / 5.00%** |

**개선이 모든 고도대에서 균일하고, 4000m 이상에서도 ATA가 101.7° → 51.6°다.**
그 고도에서는 `predAlt`가 1000m 아래로 갈 수 없어 **ClimbOut이 발동할 수 없다.**
ClimbOut 점유도 10.4% → 8.2%로 **조금만** 줄었다(효과 크기와 비례하지 않는다).

→ 연쇄 효과(초반 한 번의 차이가 판 전체 궤적을 바꾼다)로 보이지만 **직접 확인하지 않았다.**
   따라서 *"MinAlt 하나가 고고도 조준까지 개선한다"*는 인과 주장은 **하지 않는다.**

**두 지표가 반대 방향을 가리킨다** — 승은 M500이 2 많고 순이득은 M700이 1.64 높다.

**M700을 고른 이유**(M500이 나빠서가 아니다):
1. 2승 차가 유의하지 않고 **순이득은 오히려 M700이 높다**
2. 안전 여유가 작다(최소 525m, 600m 미만 1판). 규정상 **300m 미만 = 즉시 패배**
3. **M700은 네 관문을 다 통과했고 M500은 비퇴행을 하나도 안 거쳤다.**
   마감까지 11일인데 210판을 더 써서 얻을 기대이득이 분산 범위다

⚠ **더 큰 표본이면 M500이 나을 가능성을 배제하지 않는다.** 그건 열어 둔다.

⚠ **예측 항(5초 선행)은 없애지 말 것.** v22c가 실제 추락 사고
(pitch −88°에서 1800m에 걸린 뒤 **1461m를 더 잃음**) 때문에 넣은 것이다.

### 라벨만 보면 나빠 보이는 셀 하나 (실제로는 개선)

S3 방어BFM × kwon은 둘 다 FAIL인데 **사유 라벨**이
`계속 물림(30%)` → `격추/추락`으로 바뀌었다. 세부를 보면 반대다:

| | 3회 반복 분포 | 최저고도 | 사격틱 |
|---|---|---|---|
| v41 | **P1 / W0 / F2** | 1363 m | 298.3 |
| v42 | **P2 / W0 / F1** | 1146 m | 28.0 |

셀 등급은 **최악 판정**으로 매겨지므로 FAIL로 같지만 **PASS 1→2, FAIL 2→1로 개선**이다.
라벨의 "추락"은 오해를 부르는데, 최저고도 1146m로 규정 하한(300m) 훨씬 위이므로
**추락이 아니라 격추**다. Syllabus 24셀 전체 최저값도 **916m**다.

⚠ 다만 그 셀의 **사격틱이 298.3 → 28.0으로 급감**했다. 3회 중 2회가 PASS로 일찍
끝나면 평균이 내려갈 수 있으나 **확인하지 않았다.** 인과로 단정하지 않는다.
